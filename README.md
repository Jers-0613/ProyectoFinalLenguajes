\# Proyecto Final — Autómatas y Lenguajes Formales



\## Descripción



Proyecto académico para la implementación de una aplicación web relacionada con Autómatas y Lenguajes Formales.



La aplicación permitirá trabajar con diferentes funcionalidades relacionadas con el análisis de cadenas y lenguajes, además de contar con un sistema de usuarios y generación de credenciales.



\## Tecnologías



\### Frontend



\* Nuxt.js 3

\* Vue.js 3

\* Vuetify 3

\* HTML

\* CSS

\* JavaScript

\* TypeScript



\### Backend



\* .NET 8

\* ASP.NET Core

\* C#



\### Base de datos

\## Ejecución local



\### Frontend



```bash

cd frontend

npm install

npm run dev

```



El frontend estará disponible en:



```text

http://localhost:3000

```



\### Backend



El backend será ejecutado mediante .NET 8 y proporcionará la API utilizada por el frontend.
